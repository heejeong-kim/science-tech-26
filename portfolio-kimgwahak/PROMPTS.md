## 아이콘 13종 (SVG 권장 · Claude 또는 ChatGPT)

선명하고 색을 그대로 유지하려면 이미지 생성보다 **SVG 코드로 만드는 방식**을 권장함.
아이콘은 화면에서 옅은 민트(네이비 섹션에서는 흰색) 둥근 타일 위에 얹혀 보이므로 배경 없이 만듦.

| 파일명 | 의미 | 들어가는 곳 |
|---|---|---|
| ic-efficacy | 비임상 효능평가 설계 | 2장 핵심역량 1 |
| ic-data | 데이터 검증·해석 | 2장 핵심역량 2 |
| ic-global | 글로벌 외부 협업 | 2장 핵심역량 3, 5장 카드 2 |
| ic-lead | 프로젝트 리딩·의사결정 | 2장 핵심역량 4, 4장 결과 3, 5장 카드 1 |
| ic-bullet | 블릿 | 2장 JD 근거 목록 |
| ic-problem | 문제 정의 | 3장 PROBLEM |
| ic-assay | 평가법 구축 | 3장 STEP 1, 4장 결과 1 |
| ic-ai | AI 모델링 자료 | 3장 STEP 2 |
| ic-compare | 예측·실험 비교 분석 | 3장 STEP 3 |
| ic-candidate | 후보물질 도출 | 3장 STEP 4, 4장 결과 2 |
| ic-experiment | 실험·평가 | 6장 Experiment 열 |
| ic-evidence | 검증·운영 | 6장 Evidence 열 |
| ic-output | 연구 결과물 | 6장 Output 열 |

### 아이콘 세트 프롬프트
```
아래 13개 아이콘을 하나의 세트로, 각각 별도의 SVG 코드로 만들어 줘.

[스타일]
- viewBox="0 0 24 24", 배경 없음(투명), 채우기 없는 라인 아이콘
- 선 두께 1.75, 선 끝과 모서리는 둥글게(stroke-linecap/linejoin round)
- 기본 선 색은 네이비 #13284F, 아이콘마다 핵심 요소 1곳만 민트 #2EC4A6로 강조
- 13개가 같은 굵기·같은 여백(가장자리 2px)·같은 시각적 크기로 통일되게
- 글자, 숫자, 로고는 넣지 마
- 세포·현미경·Western blot 밴드·실험 그래프처럼 실험 결과로 보이는 그림은 쓰지 마

[목록] 파일명 — 표현할 내용
1. ic-efficacy — 표적 원 위에 체크 표시 (효능평가 설계)
2. ic-data — 문서 위의 돋보기 (데이터 검증·해석)
3. ic-global — 지구본과 연결된 두 점 (글로벌 협업)
4. ic-lead — 깃발 하나와 그 아래 세 점 (프로젝트 리딩)
5. ic-bullet — 작은 원 안의 점 또는 짧은 화살촉 (블릿, 14px에서도 보이게 단순하게)
6. ic-problem — 물음표 대신 끊어진 연결선 두 개 (문제 정의)
7. ic-assay — 체크리스트 칸 세 줄 (평가 기준 구축)
8. ic-ai — 노드 세 개가 연결된 작은 네트워크 (AI 모델링)
9. ic-compare — 좌우 두 원이 겹치는 벤다이어그램, 겹친 부분 민트 (비교 분석)
10. ic-candidate — 여러 점 중 하나만 민트로 둘러싼 선택 표시 (후보 도출)
11. ic-experiment — 둥근 플라스크 윤곽, 액체 선 하나만 민트 (실험·평가)
12. ic-evidence — 방패 안의 체크 표시 (검증)
13. ic-output — 상자에서 위로 나오는 화살표 (결과물)

각 아이콘은 파일명을 제목으로 달고, 복사해서 바로 .svg 파일로 저장할 수 있게 코드 블록으로 따로 줘.
```

### 이미지 생성(나노 바나나)으로 만들 때
```
1:1 정사각형 흰 배경에 4×4 격자로 라인 아이콘 13개를 배치한 아이콘 시트를 만들어 줘.
선 두께가 같은 네이비(#13284F) 라인 아이콘이고, 아이콘마다 한 곳만 민트(#2EC4A6)로 강조해 줘.
순서: 표적+체크, 문서+돋보기, 지구본+두 점, 깃발+세 점, 원 안의 점, 끊어진 연결선, 체크리스트,
노드 3개 네트워크, 겹친 두 원, 점 하나 선택, 둥근 플라스크, 방패+체크, 상자+위 화살표.
글자·숫자·그림자·배경 무늬는 넣지 마.
```
※ 이미지로 만든 아이콘은 하나씩 잘라 배경을 지운 PNG(최소 96×96px)로 저장함
