# 김서연 포트폴리오 웹뷰

강의교안의 김서연 스토리보드·최종 STAR 기반 확장본. 기존 슬라이드는 변경하지 않음.

6개 섹션: 표지, 핵심역량, 대표 프로젝트 과정, 결과, 보조 프로젝트, 기술·성과. CV 약 25% → 10% 이내, 비교 전후 각 3개월, 팀원 4명·2개 과제, 2025.01 수상은 교안의 수업용 가상 사례를 그대로 사용함. 개선 후 차트는 정확한 값이 아닌 10% 상한을 표시. 실험 샘플 수 및 재실험 감소율은 추가하지 않음. 원본 증거는 미첨부.

index.html은 웹뷰, portfolio.html은 동일한 단일 파일 보관본. PDF 저장은 브라우저 인쇄를 사용.

시각자료: 표지는 추상 생성 이미지, 섹션은 6종 SVG 아이콘. 실험 결과 사진·밴드·가상 실측 이미지를 사용하지 않음. 흐름도와 비교 차트는 교안 데이터를 HTML/CSS로 표현함.

직접 시각화 샘플: assets/visual/repeatability-demo.svg. 18개 합성값, 세트별 n=3·표본 SD 기준 CV 25%/8%. 교안의 실제 원자료를 복원한 것이 아님.
