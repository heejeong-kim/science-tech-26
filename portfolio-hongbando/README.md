# 홍반도 반도체 패키징 포트폴리오

- `index.html`: 웹사이트용 시작 파일. style.css, script.js와 같은 폴더에 보관합니다.
- `portfolio.html`: 스타일과 동작을 포함한 단일 HTML 백업. 브라우저에서 바로 열 수 있습니다.
- 기준 화면 폭: 1600px. 모바일에서는 경력 타임라인을 세로로 표시합니다.
- 글꼴: IBM Plex Sans / IBM Plex Sans KR. Google Fonts 연결에 인터넷이 필요합니다.
- PDF 저장 버튼: 브라우저 인쇄에서 PDF로 저장을 선택합니다. A4 가로, 머리글/바닥글 끄기, 배경 그래픽 켜기를 권장합니다.
- 연락처는 화면에서 직접 입력합니다. 새로 열면 초기화되며 외부 전송이나 저장은 하지 않습니다.

## 구성과 근거
강의교안의 6페이지 스토리보드에 맞춰 표지, 경력/역량, 대표 프로젝트 과정, 대표 프로젝트 결과, 보조 프로젝트 2건, 기술/직무 연결로 구성했습니다.

강의: https://heejeong-kim.github.io/science-tech-26/#portfolio-webview-option
목표 JD 근거: https://amkor.com/kr/careers/korea/ 의 기술연구소(R&D) 직무 소개. 특정 진행 중인 모집 공고가 아닙니다.

경력·성과는 사용자가 제공한 내용만 사용했습니다. 총 경력 1년 10개월은 패키징 1년 7개월과 인턴 3개월의 합계이며 학부연구생 2개월은 별도 표시했습니다.
warpage 차트의 100/약 20은 MR 기준 설명용 정규화 지수이며 절대 실측값이 아닙니다. 평가 기간·샘플 수는 추가하지 않았습니다.

## 공유
공개 주소로 배포하지 않은 로컬 완성본입니다. GitHub Pages 등에 올릴 때는 이 폴더의 index.html, style.css, script.js를 함께 업로드하거나 portfolio.html을 index.html로 사용합니다.
